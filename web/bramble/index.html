Bramble Maps

A private map app for Android. Maps are stored on your phone, so it works without a signal.

Getting the app

Bramble Maps is not public yet, so there is no download button on this page. If someone sent you a link to it, ask them for the install file (an .apk).

Install steps (Android)

  1. Open the .apk file you were given.
  2. If Android says it can't install apps from this source, tap Settings and allow it for that one app (your browser or file manager). You can switch it off again afterwards.
  3. Tap Install, then Open.
  4. On first start the app asks to download its base map. Say yes, on Wi-Fi. Then pick the regions you want under Download maps.

Good to know

  • Maps come from our own server, not from the original CoMaps download servers.
  • The app does not use Google Play Services for your location. It asks Android's own location service, and only if you allow it.
  • It is early software. Things may be rough, and some screens still carry their original CoMaps wording.
